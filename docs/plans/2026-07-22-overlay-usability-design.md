# mimi 字幕浮层易用性设计

## 交互与持久化

字幕浮层继续保持置顶、跨桌面和全屏可见，但改为可调整大小。用户未锁定浮层时，可以拖动任意空白区域改变位置，也可以拖动窗口边缘改变宽高；右下角显示低对比度的缩放提示。AppKit 自带的窗口 frame autosave 负责保存位置、尺寸和显示器信息，并在下一次启动时恢复。系统会在显示器布局改变后把窗口约束回可见区域，因此不需要维护一套容易失效的自定义坐标格式。最小尺寸为 420×100，避免把字幕压缩到无法阅读；默认仍为 820×170。

字幕框右上角增加一个低对比度设置按钮，未锁定时显示，点击后直接打开设置。设置窗口增加关于拖动、缩放和锁定行为的简短说明。锁定时窗口忽略鼠标事件，按钮和缩放提示一起隐藏，确保不会挡住视频操作。

启动时不再写入任何示例原文或译文。测试模式只负责打开设置和显示空白状态浮层，使界面自动化仍然能操作应用，但不会把 “The future is already here.” 混进真实字幕。

## 可发现性、连接恢复与验证

菜单栏图标在刘海屏或图标过多时可能被系统隐藏，因此 mimi 改为同时出现在 Dock。点击 Dock 图标会唤起设置窗口；菜单栏入口仍然保留。这样冷启动、尚未显示字幕浮层时也有稳定入口，监听期间则可以直接使用浮层里的设置按钮。

自动恢复不再根据“有音量但没有识别文本”判断断线，因为音乐、环境声或长停顿都可能触发错误重连。客户端改用 WebSocket ping/pong 健康检查：连接真实失效或 ping 超时才进行有限次数重连。静音、背景音乐和无人说话时状态保持“正在聆听”，不会反复显示“正在连接阿里云”。

验证包括：纯逻辑测试覆盖 ping 超时错误和窗口尺寸约束；完整核心测试；Swift 严格并发和 warnings-as-errors 构建；应用打包、Info.plist 与签名检查；最后通过界面自动化拖动/缩放浮层、重启应用确认 frame 恢复，并确认 Dock 点击、设置按钮、日语到中文监听状态正常。
