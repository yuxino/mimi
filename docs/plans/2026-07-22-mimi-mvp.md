# mimi MVP Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a native macOS menu-bar app that captures system audio and displays live original-language and Simplified Chinese subtitles using Alibaba Cloud Model Studio.

**Architecture:** A Swift package separates deterministic protocol/state logic in `MimiCore` from macOS integrations in `MimiApp`. ScreenCaptureKit produces 16 kHz mono PCM, a URLSession WebSocket streams it to Qwen LiveTranslate, and an observable app model drives a floating AppKit/SwiftUI subtitle window.

**Tech Stack:** Swift 6, Swift Package Manager, SwiftUI, AppKit, ScreenCaptureKit, AVFoundation, Security, URLSessionWebSocketTask, and a zero-dependency executable test harness.
