# Mimi 4K feature tour / 完整功能演示

Chinese and English versions: 125 seconds, 3840 × 2160, 60 fps. Each starts on a complete cover and includes female narration, matching captions, and an original soft score. Synthetic breath-like transition sounds have been removed.

中英文两版均为 125 秒、3840 × 2160、60 帧，第一帧即为完整封面，配有女声旁白、对应字幕与原创轻柔配乐；已移除转场呼气音效。

Freshly recorded from the installed Mimi 1.3.12 macOS app, covering service configurations, languages, subtitle controls, Immersive Mode, and settings. The new Sintel excerpt runs through actual system-audio capture and Alibaba Cloud recognition, with live English-to-Chinese translation. Both versions use new interface recordings, with their own UI language and narration. The live scene retains audio from the same native take, without narration or music over the dialogue. This edited tour is not a latency benchmark or cross-platform acceptance test.

使用已安装的 Mimi 1.3.12 macOS 应用重新录制，展示服务配置、语言、字幕控制、沉浸模式和设置。全新 Sintel 片段经过实际系统音频采集与阿里云识别，实时将英文对白翻译为中文。两版分别重录中英文界面并配对应旁白；电影字幕段保留同一次原生录制的声音，没有旁白或配乐遮盖对白。这是经过剪辑的功能演示，不是延迟基准或跨平台验收。

The tour covers service configurations, provider selection, languages, response modes, pause/resume, collapse/expand, clear, lock, window resizing, Immersive Mode, appearance, and general settings. The subtitle window is wider and centered, with 20-point centered text. See the [machine-readable provenance](full-tour-4k.json) for chapter timings and the exact source commit.

Film: *Sintel*, © Blender Foundation, [sintel.org](https://www.sintel.org), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). A new 20.7-second excerpt from the official 4K film is re-encoded beneath Mimi subtitles. The original imagery and dialogue are unchanged. The 24-second live chapter includes the lead-in and settling subtitles.

电影使用官方 4K 原片中的全新 20.7 秒片段，重新编码并叠加 Mimi 实时字幕；电影画面与对白没有改写。连续演示段为 24 秒，包含播放前后字幕显示的时间。

Voice: Microsoft Xiaoyi Neural (Chinese), Aria Neural (English), at natural pitch; no real person's voice was cloned. Artwork uses the current Mimi pink-haired headphone character. Native footage was recorded at 3024 × 1964 with variable frame timing, then cropped for the film frame. The final composition and motion graphics are 60 fps; the source movie is 24 fps. Hardware output remained muted while native system audio was captured internally.
