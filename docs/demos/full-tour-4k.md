# Mimi 4K feature tour / 完整功能演示

Chinese and English versions: 125 seconds, 3840 × 2160, 60 fps. Female narration, matching captions, an original soft score, and original film audio during the continuous subtitle scene.

中英文两版，125 秒，3840 × 2160、60 帧，配有女声旁白、对应字幕与原创轻柔配乐；连续电影字幕段落保留电影原声，没有旁白或配乐遮盖对白。

The actual Mimi 1.3.12 production frontend is operated in an isolated sample host. Native system audio, window and secure-storage calls use a demonstration adapter. The movie scene replays previously recorded real cloud-service events from the public demo, unaltered and at their original timing. No new provider request or personal credentials were used. This is an edited interface feature tour, not a native audio-pipeline, latency or cross-platform acceptance test.

实际 Mimi 1.3.12 前端在独立样例宿主中操作，原生系统声音、窗口与安全存储调用由演示适配层提供。电影片段按原始时间重放已有公开演示的真实云服务事件，没有修改返回文字；此次没有请求云服务或使用个人凭据。这是剪辑后的功能演示，不是原生音频链路、延迟或跨平台验收。

The tour covers service configurations, provider selection, languages, response modes, subtitle controls, Immersive Mode, appearance and general settings. See the [machine-readable provenance](full-tour-4k.json) for chapter timings and the exact source commit.

电影来源为 *Sintel*，© Blender Foundation，[sintel.org](https://www.sintel.org)，[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)。使用原片 02:07 起的 19.5 秒片段，重新编码并叠加 Mimi 字幕，保留原声。影片与对白没有改写。

Voice: Microsoft Xiaoyi Neural (Chinese), Ana Neural (English). Synthetic voices at natural pitch; no real person's voice was cloned. Artwork uses the current Mimi pink-haired headphone character. Interface footage is captured at UHD resolution; 60 fps describes the final composition and motion graphics, while the source movie is 24 fps.
