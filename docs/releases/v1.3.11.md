## English

## Fixes and improvements

- Prevent late translation previews in High Quality and Turbo modes from appearing after confirmed subtitles or overwriting newer previews.
- Correct OpenAI/Azure Realtime timing boundaries across multiple transcript chunks, preserving uncommitted Unicode tails and avoiding arithmetic underflow in debug builds.
- Stop Windows release processing immediately if either installer's updater signature fails verification.

## Installation notes

The macOS package is ad-hoc signed and not notarized; Gatekeeper, Screen & System Audio Recording, or Keychain approval may be required again. Windows packages are not Authenticode-signed, so SmartScreen may warn. The updater signature verifies update integrity but does not replace platform code signing.

**Full Changelog**: https://github.com/yuxino/mimi/compare/v1.3.10...v1.3.11

## 中文

## 修复与改进

- 修复高质量与极速模式下，迟到的翻译预览可能出现在已确认字幕之后，或覆盖新预览的问题。
- 修正 OpenAI/Azure Realtime 多段字幕的时间边界计算，保留尚未提交的 Unicode 尾句，并避免调试构建中的算术下溢。
- 加强 Windows 更新包的逐项签名验证，任一安装包验签失败即停止发布。

### 安装说明

macOS 包为 ad-hoc 签名，未经 Apple 公证，可能需要重新允许 Gatekeeper、屏幕与系统音频录制或钥匙串访问。Windows 包未做 Authenticode 签名，SmartScreen 可能提示警告。更新签名验证完整性，不替代平台代码签名。完整更新记录见上方链接。
