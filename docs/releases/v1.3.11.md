## 修复与改进

- 修复高质量与极速模式下，迟到的翻译预览可能出现在已确认字幕之后，或覆盖新预览的问题。
- 修正 OpenAI/Azure Realtime 多段字幕的时间边界计算，保留尚未提交的 Unicode 尾句，并避免调试构建中的算术下溢。
- 加强 Windows 更新包的逐项签名验证，任一安装包验签失败即停止发布。

## Fixes and improvements

- Prevent late translation previews in High Quality and Turbo modes from appearing after confirmed subtitles or overwriting newer previews.
- Correct OpenAI/Azure Realtime timing boundaries across multiple transcript chunks, preserving uncommitted Unicode tails and avoiding arithmetic underflow in debug builds.
- Stop Windows release processing immediately if either installer's updater signature fails verification.
