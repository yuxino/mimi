## English

### What's changed

- Add two independent switches in **Settings → General → Session export**: retain confirmed subtitles and record system audio. Both are **off by default**, including after upgrading.
- After stopping a session, export the confirmed original text and translation as a timestamped **TXT**, or export the recorded system audio as **WAV**, using the native save dialog.
- Add **System / Light / Dark** settings appearance, with English, Simplified Chinese, and Japanese labels.

### Privacy and limits

Enabling a switch is optional and its choice is remembered. Content stays in memory until you explicitly export it. Turning a switch off clears that buffer; starting a new session or quitting clears both. Export anything you want to keep before doing so. Microphone capture and automatic content saving remain disabled.

Transcript retention stops at 10,000 confirmed pairs or 2 MiB of text; audio retention stops at 64 MiB. The app shows a notice when a limit is reached. Transcript timestamps mark final confirmation time, not media playback positions. WAV omits pauses and reconnect gaps, so its timeline does not directly align with the transcript.

### Updating and verification

Open **Settings → General → Software Update**, or download the installer below. The macOS package is ad-hoc signed and not notarized; Gatekeeper, Screen & System Audio Recording, or Keychain approval may be required again. Windows packages are not Authenticode-signed, so SmartScreen may warn. Updater signatures verify integrity and do not replace platform code signing.

Automated checks cover Rust/frontend behavior, bounded retention, default-off migration, WAV structure, and file replacement. Native export checks use synthetic content in the signed macOS development app; this does not establish real-provider recording acceptance. Windows device interaction and complete in-place updater acceptance remain unverified.

**Full Changelog**: https://github.com/yuxino/mimi/compare/v1.3.12...v1.4.0

## 中文

### 本次改进

- 在「**设置 → 通用 → 会话导出**」增加两个独立开关：保留已确认字幕、录制系统音频。两项均**默认关闭**，升级后也不会自动开启。
- 停止会话后，可通过系统保存对话框，将已确认的原文、译文导出为带时间戳的 **TXT**，或将录制的系统音频导出为 **WAV**。
- 设置界面新增「**跟随系统／浅色／深色**」外观选项，文案同步支持英文、简体中文和日文。

### 隐私与限制

开关由你选择是否开启，应用会记住选择。内容仅临时保留在内存中，手动导出才会写入文件。关闭某个开关会清空对应内容；开始新会话或退出应用会清空两项内容，请提前导出需要保留的部分。仍不使用麦克风，也不会自动保存内容。

字幕最多保留 10,000 条已确认记录或 2 MiB 文字，音频最多保留 64 MiB；达到上限后停止保留并显示提示。字幕时间戳表示最终确认时间，并非媒体播放位置。WAV 不包含暂停和重连间隙，因此其时间轴不能与字幕时间戳直接对齐。

### 更新与验证说明

在「**设置 → 通用 → 软件更新**」中更新，或下载下方安装包。macOS 包为 ad-hoc 签名，未经 Apple 公证，可能需要重新允许 Gatekeeper、屏幕与系统音频录制或钥匙串访问。Windows 包未做 Authenticode 签名，SmartScreen 可能提示警告。更新签名验证完整性，不替代平台代码签名。

自动检查覆盖 Rust／前端行为、暂存上限、升级后默认关闭、WAV 格式和文件替换。原生导出检查使用签名 macOS 开发版与合成内容，不代表已完成真实服务商录音验收。Windows 实机交互和完整原地更新仍未验证。完整更新记录见上方链接。
