## English

## Fixes and improvements

- Stop reporting Listening when capture has failed or subtitles have not started.
- Show explicit error and idle labels in Chinese, English, and Japanese, with a static status indicator.
- Document a single-app recovery procedure for macOS recording access that remains denied despite an enabled permission switch.

## Installation notes

The macOS package is ad-hoc signed and not notarized; Gatekeeper, Screen & System Audio Recording, or Keychain approval may be required again. Windows packages are not Authenticode-signed, so SmartScreen may warn. The updater signature verifies update integrity but does not replace platform code signing.

**Full Changelog**: https://github.com/yuxino/mimi/compare/v1.3.9...v1.3.10

## 中文

## 修复与改进

- 修复采集失败或字幕未启动时，浮层仍显示“正在聆听”的问题。
- 为错误和未启动状态显示明确的中英日文提示，停止对应的聆听动画。
- 补充 macOS 录制权限已开启但采集仍被拒绝时，针对 Mimi 单条授权记录的恢复步骤。

### 安装说明

macOS 包为 ad-hoc 签名，未经 Apple 公证，可能需要重新允许 Gatekeeper、屏幕与系统音频录制或钥匙串访问。Windows 包未做 Authenticode 签名，SmartScreen 可能提示警告。更新签名验证完整性，不替代平台代码签名。完整更新记录见上方链接。
