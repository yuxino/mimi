## English

### What's changed

- Add a Windows x64 extract-and-run package: `mimi_1.4.3_x64-portable.zip`. Extract it and run `mimi.exe` without an installer. WebView2 must already be installed; Windows 11 normally includes it.
- Portable copies open GitHub Releases for manual ZIP updates instead of launching the NSIS updater. Existing EXE/MSI installers and their signed in-app update path remain available.

The portable ZIP does not move settings, service credentials, or exports beside the executable. They remain in the OS-managed or user-selected locations. Quit Mimi before replacing the extracted files with a newer ZIP. The Windows packages are not Authenticode-signed, so SmartScreen may warn.

The macOS build uses the same fixed self-signed release identity as v1.4.2. It is not Apple-notarized, so Gatekeeper may require **Open Anyway**. A self-signed identity does not guarantee password-free Keychain access after an update.

### Verification

Source checks, Windows installer and portable archive checks, and a native UI-test launch from the extracted Windows ZIP passed. The macOS app and DMG were verified with the pinned signing identity. A real Windows system-audio session, manual ZIP replacement across versions, and an installed macOS update with live capture were not verified.

**Full Changelog**: https://github.com/yuxino/mimi/compare/v1.4.2...v1.4.3

## 中文

### 本次更新

- 新增 Windows x64 免安装包 `mimi_1.4.3_x64-portable.zip`。解压后直接运行 `mimi.exe`，无需安装器。电脑需已安装 WebView2；Windows 11 通常自带。
- 绿色版从 GitHub Releases 手动下载新版 ZIP 更新，不会启动 NSIS 安装器。现有 EXE/MSI 安装包及其经过签名验证的应用内更新流程继续保留。

绿色版不会把设置、服务凭证或导出文件搬到程序旁；它们仍保存在系统管理或用户选择的位置。替换新版 ZIP 前请先退出 Mimi。Windows 发布包未做 Authenticode 签名，SmartScreen 可能提示警告。

macOS 版本沿用 v1.4.2 的固定自签名身份，未经过 Apple 公证；Gatekeeper 可能需要选择「仍要打开」。自签名不能保证更新后钥匙串不再询问访问权限。

### 验证范围

源码检查、Windows 安装包与绿色版归档检查，以及从解压后的 Windows ZIP 启动原生 UI 测试均已通过。macOS 应用和 DMG 已按固定签名身份验证。Windows 真实系统音频会话、跨版本手动替换 ZIP，以及 macOS 已安装版本更新后的真实采集仍未验收。
