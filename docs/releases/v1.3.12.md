## English

### What's changed

- Give the Windows setup wizard a clearer layout with Mimi's own character artwork, sharper images, and a quieter welcome and thank-you page. Installer text follows English, Simplified Chinese, or Japanese; the GitHub link on the finish page is optional.
- Add **Install and Restart Mimi** to Windows in-app updates. Mimi closes for installation and reopens when the update finishes, with matching instructions in all three languages.
- Keep the installer design in the shared desktop-installer project so future improvements stay consistent across applications. Fix the custom-language encoding used by Tauri and make preview icons match the actual installer.

### Updating

On Windows and macOS, open **Settings → General → Software Update** to check for an update, download it with progress, and install the verified package. macOS keeps a separate **Restart and Finish Update** action.

If you install this version through an older Windows release, its updater may still require you to open Mimi once after installation. Automatic reopening applies to updates started from v1.3.12 onward. Builds without the Software Update section need one manual installation.

### Installation and verification

The macOS package is ad-hoc signed and not notarized; Gatekeeper, Screen & System Audio Recording, or Keychain approval may be required again. Windows packages are not Authenticode-signed, so SmartScreen may warn. The updater signature verifies update integrity but does not replace platform code signing.

Installer layouts are checked in Windows CI. Complete updates from existing installations still need physical-device acceptance on Windows and macOS.

**Full Changelog**: https://github.com/yuxino/mimi/compare/v1.3.11...v1.3.12

## 中文

### 本次改进

- 重新整理 Windows 安装向导的排版，加入 Mimi 专属立绘，提升图片清晰度，让欢迎和感谢页面更自然。安装文案支持英文、简体中文和日文；完成页的 GitHub 链接由你选择是否打开。
- Windows 应用内更新新增「安装并重启 Mimi」。安装时自动关闭应用，完成后重新打开，三种语言的提示同步调整。
- 安装界面统一由 desktop-installer 项目维护，后续设计改进可同步到各个应用。修复 Tauri 自定义语言文件的编码问题，并让预览图标与正式安装包保持一致。

### 如何更新

Windows 和 macOS 均可在「设置 → 通用 → 软件更新」里检查更新、查看下载进度，再安装通过签名验证的更新包。macOS 保留单独的「重新启动并完成更新」操作。

如果从旧版 Windows Mimi 更新到这个版本，旧更新器可能仍需要你在安装完成后手动打开一次。从 v1.3.12 发起后续更新时，才会自动重新打开。没有「软件更新」入口的旧版本，需要手动安装一次。

### 安装与验证说明

macOS 包为 ad-hoc 签名，未经 Apple 公证，可能需要重新允许 Gatekeeper、屏幕与系统音频录制或钥匙串访问。Windows 包未做 Authenticode 签名，SmartScreen 可能提示警告。更新签名验证完整性，不替代平台代码签名。

安装界面已通过 Windows CI 检查。从现有安装版本完成整套更新的体验，仍需在 Windows 和 macOS 实机上验收。完整更新记录见上方链接。
