## 修复与改进

- 修复翻译等待期间偶尔显示原文的问题，切换字幕模式时及时清除旧预览；原文模式和同语言字幕保持可用。
- 改善停止、取消和结束音频会话时的资源释放，避免后台发送任务继续占用资源。
- 限制异常翻译响应的内存占用，改善流式响应处理，并合并重复 HTTP 依赖。本地 macOS arm64 主程序对比减少约 129 KiB（1.87%）。
- 改善 Windows 连续启动时的单实例交接，减少重复初始化带来的等待。

## Fixes and improvements

- Prevent source text from appearing while a translation is pending, and clear stale previews when switching subtitle modes. Original and same-language subtitles remain available.
- Release audio send tasks reliably when a session finishes, stops, or is cancelled.
- Bound oversized translation responses, improve streaming response handling, and share the HTTP dependency. Comparable local macOS arm64 executables are about 129 KiB (1.87%) smaller.
- Hand off repeated Windows launches before initializing another app runtime.
