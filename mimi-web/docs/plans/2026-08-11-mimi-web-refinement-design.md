# Mimi Web refinement

## Direction

The site should feel like a small editorial studio built around Mimi: soft and approachable, but still credible as a native macOS product. The dark viewing environment remains the foundation because it lets the subtitle product imagery read clearly. Mimi's new character becomes the warm guide through that environment instead of appearing only as a tiny app icon.

## Changes

- Introduce the character in the hero and final download area while keeping real product screenshots dominant.
- Add a compact trust strip for the four questions users need answered immediately: audio source, account requirement, credential storage, and system compatibility.
- Add a three-step setup section with direct links to the required Alibaba Cloud credential documentation.
- Replace the mature-content scene label with a product-safe short-drama use case.
- Move display typography toward a Chinese editorial serif and add restrained entrance and floating motion.
- Preserve responsive navigation, reduced-motion support, keyboard-readable structure, and concise download paths.

## Verification

- Run lint and production build.
- Inspect hero, setup flow, download area, and footer at desktop width.
- Inspect navigation, card stacking, and CTA layout at mobile width.
- Check for broken images, browser console errors, and horizontal overflow.
