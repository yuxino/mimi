# mimi-web

mimi 的产品官网，位于 Mimi 主仓库的 `mimi-web/` 目录。

网站围绕 macOS 原生实时翻译字幕产品制作，复用了主仓库中的 Mimi 图标、猫咪形象、字幕窗截图和真实使用场景素材。

## 本地开发

```bash
npm install
npm run dev
```

常用命令：

```bash
npm run build
npm run lint
npm run preview
```
